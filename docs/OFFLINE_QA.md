# 离线识别验证记录

本记录说明 v0.1.0 开发验证的范围，不能代替 Android 真机兼容性测试。测试日期为 2026-09-25，识别全部使用单线程 CPU / WebAssembly，模型、运行时和录音均来自本机。

## 模型选择

中文样本由 Windows Microsoft Huihui Desktop 在本机合成，为 16 kHz 单声道 PCM WAV，约 9.4 秒。合成语音与真实人声不同，以下结果仅用于同一输入下的模型选择，不构成准确率或设备速度保证。

原文：

> 大家好，这是一段离线语音识别测试。我们可以录音，生成逐字稿，并且导出文档。

| 候选 | 本机观测时间 | 原始识别输出 |
| --- | --- | --- |
| Whisper Tiny q8 | 4.88 秒 | 大家好,這是一段離現於因時別測試 / 我們可以錄音,聲稱主字搞並且到出文章 |
| Whisper Base q8 | 5.05 秒 | 大家好,這是一段離線語音時別測試。/ 我們可以錄音、聲稱逐字稿、並且倒出文章。 |
| **Whisper Small q8（最终选择）** | **13.29 秒** | **大家好,这是一段离线语音识别测试。/ 我们可以录音,生成竹子稿,并且导出文档。** |

Small 的这段样本仍将「逐字稿」识别成「竹子稿」，需要人工核对。它比 Tiny/Base 更适合本项目的中文用途，因此默认安装包仅保留 Small。模型内存和计算量较大，手机转写可能明显慢于录音时长；尚未验证 Android 真机上的速度和稳定性。

## 已完成检查

- 生产版 Vite Web Worker 在 Chrome 中对上面的中文 WAV 完成了真实推理。网络拦截器拒绝并统计所有非本机请求，测试期间外部请求数为 **0**。
- 候选评估使用相同的生产推理代码；Small 模型通过本机 HTTP 流式服务加载。首次尝试使用 Playwright 将 249 MB 模型体通过调试协议转发时浏览器关闭，改为实际安装包所用的直接文件加载方式后正常完成。
- PCM WAV 多声道解码、采样率转换、长音频分段覆盖、时间戳偏移、静音、取消、中文 TXT 与 Word OOXML 内容有自动化单元检查。
- 模型文件固定至不可变提交，下载时核对 LFS SHA-256 或 Git blob ID；`npm run model:prepare -- --verify` 可在断网状态复验包内资源。
- 英文合成音频在初始 Tiny 版本的生产浏览器和 Electron 自定义协议内识别完整；Electron 同时验证了 Word 导出。最终 Small 安装包仍需遵循发布流程完成启动与资源检查。

这些检查没有模拟真实麦克风驱动、Android 屏幕授权界面或手机后台策略。真机录音与录屏测试范围以发布说明为准。
