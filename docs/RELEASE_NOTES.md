声记首个预览版本：Windows / Android 录屏、录音、完全本地的离线逐字稿，以及 Word `.docx` 导出。

下载说明：

- `*-windows-x64-portable.exe`：Windows 10/11 x64 免安装程序，未进行商业代码签名。
- `*-android-dev.apk`：Android 侧载测试包，开发签名，未上架商店；不同构建的开发签名可能不同，覆盖安装失败前请先导出资料。
- `SHA256SUMS.txt`：下载文件校验值。

安装包已包含 Whisper Small 多语言量化模型，首次启动无需下载模型、无需 API Key。为改善中文识别，模型权重约 249 MB；手机识别速度和内存需求较高。转写在录制结束后执行；结果需要校对，单次时长上限 30 分钟。Android 录屏声音来自麦克风，不包含其他 App 内部音频。

当前没有 iOS 安装包。请在重要使用前先做一段短录制，检查设备权限、声音、转写与导出结果。完整说明、构建方式和已知限制见仓库 README。
