# 隐私与数据说明

声记的录制、音频解码、识别和文档生成在本机完成。应用不要求注册、API Key 或云端语音服务，不内置分析统计、广告或崩溃报告上传。

## 保存的数据

- 原始录音或录屏、用于识别的音频、标题、创建时间和逐字稿保存在本机应用资料库中。
- Windows 使用 Electron 的应用数据目录及 IndexedDB。即使程序是免安装单文件，资料库仍保存在当前 Windows 用户的应用数据目录中。
- Android 原生录制文件保存在应用私有存储；界面资料库使用本地 WebView 存储。
- 模型与推理引擎打包在应用中，不含个人资料。
- 应用数据没有额外的应用层加密；设备账户与操作系统保护仍然重要。

## 权限用途

麦克风权限用于录音。屏幕捕获只在用户主动选择录屏并完成系统／应用选择后启动。Android 录制期间显示前台服务通知，可由通知停止。

## 导出与删除

导出文件由用户选择保存或分享。使用第三方分享应用可能产生第三方网络传输，该行为取决于所选应用。声记不会替用户上传文件。

应用内删除资料条目与操作系统卸载／清理数据会影响本机保存内容；已经导出的副本不会随条目删除。重要资料请独立备份。当前版本没有云端恢复机制。

## 构建时的网络

开发者下载 npm/Gradle 依赖、Electron 和离线模型，以及 GitHub Actions 构建／发布，需要网络连接。这与安装后处理用户录制内容的离线流程不同。仓库不应包含真实录音、逐字稿、用户数据、密钥或访问令牌。
