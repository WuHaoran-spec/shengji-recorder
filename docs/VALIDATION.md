# v0.1 验证记录

验证日期：2026-09-25。以下是开发验证结果，不代表所有电脑、手机和录音环境的表现。

## 已执行

- TypeScript 类型检查、Vite 生产构建。
- 8 项单元测试：PCM WAV 解码、损坏文件拒绝、取消、重采样、长音频分段、静音、跨段时间戳、中文 DOCX 结构与内容。
- 4 项浏览器流程测试：导入、编辑、Word 导出与重启后保存；真实 MediaRecorder 配合 Chromium 合成麦克风；桌面与手机尺寸布局；存储空间不足时保留告警并可导出原始录制。
- Electron 实际运行：本地安全来源、无 Node 渲染器、沙箱、外网阻断、无效录屏授权拒绝、摄像头拒绝。
- Electron 使用合成麦克风生成并保存音频；仅捕捉测试 App 自己的窗口生成 WebM，未录制真实麦克风、整个桌面或其他应用。
- Whisper 本地 WASM 推理：对本机合成的中英文 WAV 生成文字，测试时阻断并统计外部网络请求；识别期间没有外网请求。
- Windows 打包、Android Gradle 编译由 GitHub Actions 执行。发布作业必须等待两端成功，才会附加下载文件。

## 中文模型选择

在同一 Windows 测试环境，对约 9 秒中文合成语音比较 tiny、base 与 small 量化模型。Small 识别约耗时 13 秒，明显减少了 tiny/base 的同音字错误，因此作为默认内置模型。此时间不代表手机性能。

样本文字为「大家好，这是一段离线语音识别测试。我们可以录音，生成逐字稿，并且导出文档。」Small 正确识别大部分文字，但将「逐字稿」识别成「竹子稿」。这也是保留手工校对功能的原因。不能把机器输出视作无误记录。
