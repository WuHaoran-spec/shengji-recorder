# 安全反馈

当前维护范围为最新的 v0.1 预览版本。预览版未经过独立安全审计。

如发现可访问设备文件、越权调用原生录制、上传本机资料或绕过录制授权的漏洞，请使用仓库的私密漏洞报告功能（若维护者已启用）。没有私密渠道时，可先发一个不含敏感细节的 Issue，请维护者安排私密沟通；不要在公开 Issue 中附带真实录音、个人信息或利用代码。

## 已实施的边界

- Electron：沙箱与上下文隔离开启、Node 集成关闭；预加载脚本只暴露枚举捕获来源和选择来源两个方法。
- IPC 校验调用主窗口与可信地址。屏幕选择只授权一次，30 秒后过期，不自动选择第一个屏幕。
- 自定义 `shengji://app/` 协议仅提供构建目录中的静态文件，不提供任意文件读取。
- 限制页面导航、弹窗、WebView、摄像头和其他未需要权限。桌面运行期阻断远程 HTTP(S) 和 WebSocket。
- 离线识别固定本地模型来源。缺少模型时显示错误，不自动改用云端识别。

## 发布签名

当前 Windows 程序没有商业代码签名；Android 下载包使用开发签名。SHA-256 校验只能帮助核对下载文件，不能替代可信发布签名。正式分发应配置稳定签名密钥并保存在受限 CI secrets／签名服务中。

依赖安全更新、Android 权限策略变化以及操作系统兼容性需要持续维护。提交安全修复时，请提供最小复现步骤与验证方式。
